## 一眼看懂 Shadow

Sunny 沒有 `null`，也沒有 `try/catch`。可能失敗的函數回傳 `String | Shadow`，呼叫者用 `match` 面對它：

```sunny
fn userShow(id: Int) -> String | Shadow {
    if id <= 0 {
        out Shadow("invalid id")
    }
    out "User #" + to_string(id)
}

match userShow(-1) {
    is String s -> print(s)
    is Shadow e -> print("Error:", e.message)
}
```

輸出：`Error: invalid id`。點程式碼右上角的「試玩」就能在瀏覽器裡直接執行。

不可變是預設值，改動 `lit` 會得到清楚的訊息：

```sunny
lit x = 1
x = 2   // cannot reassign 'x': lit bindings are immutable (the sun never changes)
```

## 它是怎麼做出來的

從原始碼到結果，整條管線都是自己寫的，沒有使用 parser generator：

| 階段 | 做什麼 |
|------|--------|
| Lexer | 逐字元掃描，產生 Token |
| Pratt Parser | 9 個優先級的運算子解析，產生 AST |
| Linter | 檢查 Resource Action 命名 |
| Evaluator | 樹走訪求值；錯誤以 Shadow 傳遞 |
| Markdown / Template | 內建引擎，用來產生這個網站 |
| HTTP Server | 函數名稱自動路由 |
| WebAssembly | 同一個求值器編譯成 WASM，驅動 Playground |

想看細節：[實作原理](internals.html)。

## 安裝

```bash
git clone https://github.com/AdaaWu/sunny-lang.git
cd sunny-lang
cargo build --release
```

執行檔位於 `target/release/sun`，可以加入 PATH。

```bash
sun hello.sunny          # 執行檔案
sun                      # 進入 REPL
sun serve app.sunny      # 啟動 HTTP Server
```

## In English

Sunny is a full-stack programming language written in Rust. It is immutable by default (`lit` vs `glow`), has no `null` and no exceptions (failures are a first-class `Shadow` value that you must `match` on), and maps function names such as `productIndex()` to HTTP routes automatically.

The whole toolchain is hand-written: lexer, Pratt parser, tree-walking evaluator, linter, Markdown and template engines, and an HTTP server. The same evaluator is compiled to WebAssembly to power the in-browser [Playground](playground/index.html), and this documentation site is generated by a Sunny program, [`site.sunny`](https://github.com/AdaaWu/sunny-lang/blob/main/site/site.sunny). The code lives on [GitHub](https://github.com/AdaaWu/sunny-lang), with 180 passing tests. The documentation is in Traditional Chinese; the [internals page](internals.html) walks through the architecture.
